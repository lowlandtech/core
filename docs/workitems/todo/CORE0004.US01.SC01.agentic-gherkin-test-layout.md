## Outcome and scope

Make `src/test` follow the shared agentic-gherkin Given/When/Then acceptance layout while preserving the existing Core contract, trim, graph and package-consumer regression behavior. This is a test migration; it does not change Core production APIs or certify any open M2/M3/M4 acceptance criterion.

## Current gap

`CoreContractsTests.cs`, `CoreTrimmingAcceptanceTests.cs` and `GraphContractAcceptanceTests.cs` use broad xUnit classes and multi-assertion Facts. They do not have story/scenario paths, one Given and one When per scenario, or uniquely tagged, single-observation UAC Facts. The Core engineering adapter documents that no native scenario layout checker currently exists. Preserve the existing five Backend parity fixtures and all current test identities/evidence while mapping them to the shared grammar.

## Acceptance criteria

- [ ] UAC01: Inventory every existing Core test and its source workitem/UAC or regression purpose before moving it; retain all accepted behaviors, fixtures and traceability without renumbering existing acceptance identities.
- [ ] UAC02: Core scenarios use story/scenario files, one Given, one When, a captured result and one direct Shouldly assertion per uniquely tagged UAC Fact; shared mechanics live in reusable fixtures/use cases and do not duplicate production behavior.
- [ ] UAC03: A Core-owned layout gate detects invalid scenario paths, missing/duplicate UAC traits, extra Given/When steps, multiple assertions and empty or skipped selections. Wire it into Core's documented verification commands without claiming another lane's checker as Core proof.
- [ ] UAC04: The migrated suite executes the same contract, trim and Backend parity behavior against production code, with exact selected/executed/skipped Fact counts and no loss of existing regression coverage.
- [ ] UAC05: Core build, focused tests, package preflight and the Core-only trimmed consumer remain green; record exact command exits and package/consumer evidence. No package publication is implied by this test-layout work.
