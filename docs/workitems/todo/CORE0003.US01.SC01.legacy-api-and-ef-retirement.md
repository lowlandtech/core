## Outcome and scope

After the new shared contracts work in the packaged Harness/Backend/Plugins proof, remove old Core graph/plugin APIs that no supported consumer uses and preferably remove `Microsoft.EntityFrameworkCore` from the Core package closure. Preserve old consumers through an explicit compatibility version or migration path; do not delete an API solely because local search finds no reference.
