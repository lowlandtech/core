### Core assessment — compatibility with the M2-001 consumer pins — 2026-10-27

M2-001 delivered `LowlandTech.Core 2026.10.3-20261027163000` (SHA256
`2feb87ff6bf22db98a757664d87769ff7a40486b3c56e98f4ad4b7a3df6b8326`, source

The delivered candidate is additive to the M2-001 consumer pins, so a
separately versioned `LowlandTech.Core.Contracts` is compatible with them as
they stand:

- Harness pins `LowlandTech.Core [2026.10.2-202610242]`
  (`harness/Directory.Build.props`, `HarnessMigrationPackageVersion`) in
  `src/test`, `src/infrastructure` and `src/shell`. That pin is unchanged and
  still resolves.
- Components pins `LowlandTech.Core [$(LowlandTechCoreVersion)]` in
  `components/src/lib/LowlandTech.Components.csproj`. The pin is supplied per
  consumer and is unchanged.
- Builder and Coder carry local copies of the Core contracts; Foundry carries
  its own build-only copy. The Backend consumes no Core package.

Compatibility conditions a `LowlandTech.Core.Contracts` release has to meet:

1. a distinct package id and assembly name, so the `LowlandTech.Core` identity
   and its `2026.10.3-*` version line stay untouched and no consumer pin moves;
2. no dependency on `LowlandTech.Core`, so the resolved closure of every
   existing Core consumer is unchanged;
3. no EF Core, ASP.NET Core or database dependency, which keeps UAC04
   measurable by the same package preflight;
4. a namespace root that does not reuse the legacy Core names
   (`LowlandTech.Core.Graph.Entities.Node`,
   `LowlandTech.Core.Plugins.PluginDescriptor`) for the Backend semantics, which
   keeps UAC05 true;
5. its own immutable version line, so a contract upgrade never forces a
   `LowlandTech.Core` upgrade.

Risk to watch, not a pin incompatibility: the M2-001 candidate marks the
dynamic plugin-discovery boundary with `RequiresUnreferencedCode`, so a
consumer that enables the trim analyzer sees IL2026 at
`PluginDiscovery.DiscoverApiPlugins`/`DiscoverAppPlugins` and at
`PluginHostExtensions.AddBackendPlugins`/`AddFrontendPlugins`. That is the
intended contract and it belongs to the Harness M8-007 closure question.
