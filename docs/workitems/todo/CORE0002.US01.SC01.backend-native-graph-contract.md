## Outcome and scope

Produce a separately versioned, data-only graph/transition contract from this repository based on the active Backend `Domain` and `Core/Transitions` semantics. Include stable identity, scope, revision/hash, transition definition, schema, capability reference and validation/diagnostic types needed by external data-defined plugins. Do not transplant Backend EF entities, GraphContext, Kernel, policy or database migration into the shared package. Avoid the old Core `Node`/`PluginDescriptor` names where their semantics differ.

## Acceptance criteria

- [ ] UAC01: Exact serialized Backend transition definitions round-trip through the shared package without semantic or wire drift.
- [ ] UAC02: Backend and an external package-only plugin compile and validate against the same package identity/version, without sibling ProjectReference or duplicate public contract types.
- [ ] UAC03: Invalid owner, schema, scope, capability reference and content hash produce stable refusal diagnostics before graph publication.
- [ ] UAC04: Package preflight proves no EF Core, ASP.NET, database or host-runtime dependency in the new contract assembly.
- [ ] UAC05: Existing `LowlandTech.Core` consumers and M2-001 package identity remain available during the cutover; no existing package is silently replaced.
