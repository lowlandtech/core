competing `LowlandTech.Core` package, so the retirement state is now measured
instead of narrated. The measurement is the new repository-owned gate
`eng/verify-producers.py`, exposed as `coordinator.ps1 -Command verify-producers`
and asserted by the new acceptance Fact

(`UAC01_OnlyCorePublishesTheCorePackageIdentities`).

checkout that publishes a package while its own project file claims it cannot

consumer, not a producer, and is never a candidate. Every producer is named
with the lane that owns its checkout.
